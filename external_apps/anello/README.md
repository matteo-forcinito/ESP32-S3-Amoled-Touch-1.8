# Anello

App esterna: gioco arcade ad anello, pensato per gli schermi tondi. Codice in
`watch-os-common/anello/main`.

- Muovi la racchetta lungo il bordo (dito intorno allo schermo o knob) e rompi
  gli anelli di cristallo; ogni livello: palla piu' veloce, racchetta piu' corta,
  cristalli piu' duri. Tre palline, record salvato.
- Indietro mette in pausa; una seconda volta propone l'uscita.
- Build: `idf.py build`. Versione: override `ANELLO_VERSION`.
